# 🎬 Movie Rating Prediction with Python

## 📌 Project Overview

This project is part of the CodSoft Data Science Internship.

The objective of this project is to build a Machine Learning model that predicts movie ratings based on features such as genre, director, and actors.

---

## 🎯 Objective

To develop a regression model that accurately predicts movie ratings using historical movie data.

---

## 📂 Dataset

The dataset contains movie-related information such as:

- Genre
- Director
- Actor 1
- Actor 2
- Actor 3
- Rating (Target)

---

## 🛠 Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

---

## 🤖 Machine Learning Algorithm

- Random Forest Regressor

---

## 📊 Workflow

1. Load Dataset
2. Data Cleaning
3. Handle Missing Values
4. Encode Categorical Features
5. Train-Test Split
6. Train Model
7. Predict Ratings
8. Evaluate Model
9. Visualize Results

---

## 📈 Evaluation Metrics

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score
